# 需求解析报告

## 报告摘要

| 项目 | 内容 |
|------|------|
| 需求名称 | 从百度首页进入百度热搜 |
| 目标站点 | https://www.baidu.com/ |
| 到达页面 | https://top.baidu.com/board?platform=pc&sa=pcindex_entry |
| 范围 | 打开首页，点击「百度热搜」，进入热搜榜。不覆盖登录、搜索提交、榜单切换、接口改写 |

页面上能看到的入口文案是「百度热搜」。截图里高亮的是带 `aria-label="百度热搜"` 的标题区域。到达地址以本次给出的 URL 为准。

## 测试点清单

### 正向

| ID | 测试点 | 说明 |
|----|--------|------|
| TP-001 | 打开首页 | 【维度：功能】【方法：场景法】访问 https://www.baidu.com/ 后页面可用，能看到搜索入口 |
| TP-002 | 热搜入口可见 | 【维度：UI】【方法：场景法】首页上能看到「百度热搜」，并且可以点击 |
| TP-003 | 进入热搜榜 | 【维度：功能】【方法：场景法】点击「百度热搜」后打开热搜榜，地址为 https://top.baidu.com/board?platform=pc&sa=pcindex_entry |
| TP-004 | 热搜榜可识别 | 【维度：UI】【方法：场景法】新页面标题或页头能看出是百度热搜，不是空白页 |

### 逆向

| ID | 测试点 | 说明 |
|----|--------|------|
| TP-005 | 入口不可用 | 【维度：功能】【方法：错误推测】首页没有可点击的「百度热搜」时，不能当成进入成功 |
| TP-006 | 目标页打不开 | 【维度：兼容】【方法：错误推测】热搜榜地址不可达时，应表现为打开失败，而不是停在首页还报成功 |
| TP-007 | 弹窗被拦截 | 【维度：兼容】【方法：错误推测】若热搜在新窗口打开且被浏览器拦截，应能发现没有进入热搜榜 |

### 边界

| ID | 测试点 | 说明 |
|----|--------|------|
| TP-008 | 地址参数 | 【维度：功能】【方法：边界值】到达地址应包含 `platform=pc` 与 `sa=pcindex_entry`。多出来的参数是否仍算通过，见待确认问题 |
| TP-009 | 慢网打开 | 【维度：性能】【方法：边界值】首页或热搜榜加载慢时，应等待页面就绪，不用固定时长硬等 |
| TP-010 | 入口不止一处 | 【维度：UI】【方法：等价类】页面上若有多处「百度热搜」，要点的是首页热搜标题这一处，而不是页脚或其他链接 |

## 待确认问题

| ID | 问题 | 建议确认 |
|----|------|----------|
| Q-ENTRY-001 | 点击落点是标题上的「百度热搜」，还是包住它的链接 | 截图高亮的是 `aria-label="百度热搜"` 的标题。确认可点区域后再收窄 |
| Q-ENTRY-002 | 热搜榜是新窗口打开，还是当前页跳转 | 两种都要能判断「已经离开首页并到达指定地址」 |
| Q-ENTRY-003 | 地址必须逐字等于给出的 URL，还是只要主机、路径和这两个参数一致即可 | 建议至少校验主机 `top.baidu.com`、路径 `/board`，以及 `platform=pc`、`sa=pcindex_entry` |
| Q-ENTRY-004 | 除地址外，是否要断言榜单内容，例如出现热搜词 | 本次范围只要求进入该页。榜单条文、小说/电影切换不在本次需求内 |
| Q-ENTRY-005 | 未登录是否为前置条件 | 截图为未登录。建议默认不登录即可进入热搜榜 |

## 功能用例

### TC-ENTRY-001 打开百度首页

- **前置条件**：可访问公网，未要求登录
- **步骤**：打开 https://www.baidu.com/
- **预期**：页面可用，能看到搜索入口
- **设计依据**：场景法，P0

### TC-ENTRY-002 点击百度热搜进入热搜榜

- **前置条件**：已打开百度首页，能看到「百度热搜」
- **步骤**：点击「百度热搜」
- **预期**：进入 https://top.baidu.com/board?platform=pc&sa=pcindex_entry ，页面可识别为百度热搜
- **设计依据**：场景法，P0

### TC-ENTRY-003 热搜入口不可点击时不得判成功

- **前置条件**：首页未出现可点击的「百度热搜」
- **步骤**：查找并点击「百度热搜」
- **预期**：无法进入热搜榜，结果为失败
- **设计依据**：错误推测，P1
