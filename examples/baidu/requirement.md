## 功能用例

### TC-BAIDU-001 打开百度首页

- **前置条件**：可访问公网
- **步骤**：打开 BASE_URL，等待搜索框
- **预期**：标题包含“百度”，搜索框可见
- **设计依据**：场景法，P0 冒烟

### TC-BAIDU-002 点击百度热搜进入榜单

- **前置条件**：已打开首页
- **步骤**：点击热搜入口
- **预期**：地址包含 top.baidu.com
- **设计依据**：场景法，P0

### TC-BAIDU-003 捕获热搜页自己打开的榜单页面请求

- **前置条件**：已打开首页
- **步骤**：点击热搜，记录页面自己打开的 /board
- **预期**：拦截记录里有该文档请求
- **设计依据**：场景法，P1。当前热搜榜由文档导航打开，不再额外请求 /api/board

### TC-BAIDU-004 校验热搜榜单页面响应

- **前置条件**：已打开首页
- **步骤**：读取页面自己打开的 /board 响应
- **预期**：状态 200，标题包含“热搜”
- **设计依据**：场景法，P1

### TC-BAIDU-005 弱网下延迟热搜榜单页面

- **前置条件**：已打开首页
- **步骤**：先对 /board 加延迟，再点击热搜
- **预期**：耗时不低于延迟，状态 200
- **设计依据**：边界值，P2

### TC-BAIDU-006 改写热搜榜单查询参数

- **前置条件**：已打开首页
- **步骤**：把 /board 的 tab 改成 novel，再点击热搜
- **预期**：转发 URL 和最终地址都含 tab=novel，状态 200
- **设计依据**：边界值，P2

### TC-BAIDU-007 保存热搜榜单请求和响应

- **前置条件**：已打开首页
- **步骤**：点击热搜后导出 JSON
- **预期**：文件存在且包含 /board，不含 Cookie、Authorization 原文
- **设计依据**：场景法，P1
